zoon support

zoon connects to Apple Music on iPhone, Mac, and Apple TV. Subscription catalog streaming requires an active Apple Music subscription.

For help, contact arjun.mahanti@gmail.com. Include the platform, OS version, zoon version, and a description of the issue. Do not send passwords or Apple Account verification codes.

If Apple Music will not connect, verify your Apple Music account/subscription and grant zoon access when prompted. If pins are not syncing, verify that each device uses the same iCloud account and has internet access.

On Mac, use the arrow keys to navigate lists and Return to activate an item. Use the minus button beneath the navigation card to hide it and the white capsule near the window controls to restore it.

On Apple TV, use Siri Remote arrows and Select to browse. Play/Pause controls playback. Back/Menu returns to the previous library page, hides the browser from Home, and restores the browser when hidden. Hold Select on a music item for pin options.
