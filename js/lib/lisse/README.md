# Lisse core 0.7.3

Unmodified browser ES modules from the official `@lisse/core@0.7.3` npm package.
Source: https://github.com/JaceThings/Lisse (MIT; see LICENSE).
Package: https://registry.npmjs.org/@lisse/core/-/core-0.7.3.tgz
SHA-1: 98d211203fadb32c113f435d44596f818cbb121f

The path-only entry point is served locally so Jekyll needs no Node build step,
third-party runtime request, or framework. Source maps are intentionally omitted.
API documentation: https://github.com/JaceThings/Lisse/wiki/API-Reference

To update, download the official npm package with `npm pack --ignore-scripts`,
verify its provenance/license, and copy path.js plus its imported chunk and LICENSE.
